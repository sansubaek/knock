# knock 개인정보처리방침

시행일: 2026년 [ ]월 [ ]일

knock(이하 "운영자")은 개인정보 보호법에 따라 이용자의 개인정보를 보호하고, 관련 고충을 빠르게 처리하기 위해 이 방침을 공개합니다.

## 1. 개인정보를 쓰는 목적

- 회원 가입과 로그인, 본인 확인, 만 14세 이상 여부 확인
- 케이스 등록(활성화), 페이지 제공, 분실 모드 운영
- 방명록, 노크, 명함 교환, 분실 메시지 전달
- 베타 테스터 선정 연락, 케이스 제작·발송
- 문의와 신고 처리, 부정 이용(도배, 무작위 입력) 방지
- 서비스 개선을 위한 이용 통계 (개인을 알아볼 수 없는 형태)

## 2. 모으는 개인정보

| 구분 | 항목 | 필수 여부 |
|---|---|---|
| 회원 가입 | 이메일 주소 또는 카카오 계정 식별값, 닉네임, 만 14세 이상 확인 여부 | 필수 |
| 페이지 | 회원이 직접 적거나 올린 이름, 소개, 사진, 링크, 연락처(knock. 명함) | 선택 (회원이 정함) |
| 베타 신청 | 이름 또는 닉네임, 연락처(이메일 또는 인스타그램), 폰 기종, 원하는 디자인 | 필수 (디자인은 선택) |
| 케이스 발송 | 받는 사람 이름, 주소, 전화번호 | 발송할 때 필수 |
| 문의 | 이메일 주소, 문의 내용, 케이스 ID | 필수 (케이스 ID는 선택) |
| 방명록 (방문자) | 닉네임, 남긴 글 | 필수 |
| 명함 교환 (방문자) | 이름, 연락처, 소속·직함, 메모 | 이름·연락처 필수 |
| 분실 메시지 (습득자) | 메시지, 발견 장소, 연락처 | 메시지만 필수 |
| 자동으로 생기는 정보 | 접속 IP와 브라우저 정보를 되돌릴 수 없게 변환한 값, 브라우저 종류, 방문 시각, 로그인 유지 쿠키 | 자동 |

원래 IP 주소는 저장하지 않습니다. 변환한 값은 도배 방지와 방문자 수 계산에만 씁니다.

## 3. 보관 기간

| 항목 | 기간 |
|---|---|
| 회원 정보, 페이지, 받은 방명록·명함·분실 메시지 | 탈퇴할 때 바로 삭제 |
| 베타 신청 정보 | 베타 종료 후 3개월 |
| 문의 내용 | 처리 끝난 뒤 1년 |
| 방문 기록 | 1년 |
| 계약·청약철회 기록, 대금 결제·재화 공급 기록 (판매 시작 후) | 5년 (전자상거래법) |
| 소비자 불만·분쟁 처리 기록 (판매 시작 후) | 3년 (전자상거래법) |

## 4. 파기 절차와 방법

보관 기간이 끝나거나 목적을 이루면 바로 지웁니다. 데이터베이스와 저장소의 전자 파일은 복구할 수 없는 방법으로 지우고, 종이 문서는 분쇄합니다. 법령 때문에 보관해야 하는 정보는 다른 정보와 분리해서 보관하고, 그 목적 외에는 쓰지 않습니다.

## 5. 다른 사람에게 제공

운영자는 이용자의 개인정보를 다른 회사나 사람에게 제공하지 않습니다. 법령에 특별한 규정이 있는 경우는 예외입니다.

방문자가 명함 교환이나 분실 메시지로 남긴 정보는, 방문자가 직접 그 페이지의 주인에게 전달하려고 남기는 것입니다. 이 정보는 페이지 주인에게만 보입니다.

## 7. 국외 이전

위 업체 중 일부는 해외 회사이고, 서버가 해외에 있을 수 있습니다.

| 받는 곳 | 나라 (서버 위치) | 옮기는 항목 | 시기와 방법 | 목적 | 보관 기간 |
|---|---|---|---|---|---|
| Supabase Inc. | 미국 회사, 서버 [대한민국(서울) 또는 해당 지역] | 2번의 모든 항목 | 서비스 이용 시 네트워크로 전송 | 데이터 저장, 로그인 | 3번의 기간 |
| Vercel Inc. | 미국 회사, 서버 [대한민국(서울) 또는 해당 지역] | 접속 정보, 요청 내용 | 서비스 이용 시 네트워크로 전송 | 웹사이트 운영 | 처리 후 바로 또는 업체 정책에 따름 |

국외 이전을 원하지 않으면 가입하지 않거나 탈퇴할 수 있습니다. 다만 이 경우 서비스를 이용할 수 없습니다.

## 8. 이용자의 권리

이용자는 언제든 자기 개인정보를 보거나, 고치거나, 지우거나, 처리를 멈춰달라고 요청할 수 있습니다. 내 knock 화면에서 직접 고치거나 탈퇴할 수 있고, 문의하기나 아래 이메일로 요청해도 됩니다. 운영자는 10일 안에 처리합니다. 대리인을 통해서도 요청할 수 있습니다.

## 9. 만 14세 미만

knock은 만 14세 미만에게 회원 가입을 받지 않습니다. 가입할 때 만 14세 이상인지 확인하고, 만 14세 미만이 가입한 사실을 알게 되면 바로 계정과 정보를 지웁니다.

## 10. 안전하게 지키는 방법

- 모든 통신은 암호화(HTTPS)해서 주고받습니다.
- 데이터베이스는 계정마다 자기 정보만 읽고 쓸 수 있게 접근 규칙을 겁니다.
- 활성화 코드와 페이지 암호는 원래 숫자를 저장하지 않고, 되돌릴 수 없게 변환해서 저장합니다.
- 관리자 권한은 최소한의 사람에게만 주고, 관리자가 한 일은 기록합니다.
- 무작위 입력과 도배를 막기 위해 시도 횟수를 제한합니다.

## 11. 쿠키

knock은 로그인 상태를 유지하는 쿠키와, 암호 잠금 페이지를 연 상태를 1시간 동안 기억하는 쿠키만 씁니다. 광고나 추적용 쿠키는 쓰지 않습니다. 브라우저 설정에서 쿠키를 막을 수 있지만, 그러면 로그인이 유지되지 않습니다.
